# TASK-5-Data-Analysis-on-CSV-Files-
This project is part of the Python Developer Internship at Elevate Labs. The objective of this task is to perform data analysis on a sales CSV dataset using Python, Pandas, and Matplotlib, and generate meaningful insights with visualizations.

## 📂 Project Contents
- `Task5_Data_Analysis.ipynb` – Jupyter Notebook with complete analysis  
- `Supermarket_sales_data.csv` – Dataset used for the task  
- `images/` – Charts generated during analysis (optional)  
- `README.md` – Documentation
- 
## 🔍 Objective
- Load CSV data using Pandas  
- Perform data cleaning & exploration  
- Use `groupby()`, `sum()`, filtering, and statistical functions  
- Generate visualizations (bar chart, line chart etc.)  
- Present insights from the dataset
